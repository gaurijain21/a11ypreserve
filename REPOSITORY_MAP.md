# A11yPreserve repository map

Canonical root: `C:\Gauri\a11ypreserve`

- `corpus/` — controlled DOCX fixtures, manifests, render QA, and frozen corpus records.
- `contracts/` — source-preservation contracts and comparator specifications.
- `evidence/` — source and destination evidence records.
- `results/` — frozen V2 results and experiment reports.
- `integrated_study/` — separate multi-feature sanity-check study.
- `research/` — research decisions, scope, claims, methodology, and V3 planning.
- `v3/` — V3 variant, repeatability, and methodology-hardening work.
- `artifact/` — sanitized V2 replication-artifact source.
- `artifact_v3/` — V3 artifact source retained separately.
- `scripts/` — conversion, extraction, oracle, comparator, audit, analysis, and packaging scripts.
- `tests/` — project test material, with V2/V3 scope documented by nearby reports or filenames.
- `paper/` — canonical manuscript source, bibliography, audits, and historical build records.
- `submission/` — venue comparisons, recommendation, anonymized submission copies, PDFs, checklists, and artifact archives.
- `final_methodology/` — final methodology and protocol-strengthening records.
- `final_review/` — hostile review, claim, number, citation, and artifact audits.
- `final_strengthening/` — final evidence, parser, comparator, and loss-case strengthening records.
- `docs/` — conformance-suite and project documentation.
- `pilot/`, `pilot2/`, `pilot3/` — historical feasibility and pilot-stage work; machine-specific runtimes and profiles are excluded.

The root `.git` directory is the only authoritative Git metadata. The old nested checkout under the destination was an interim duplicate and is not the canonical project root.
