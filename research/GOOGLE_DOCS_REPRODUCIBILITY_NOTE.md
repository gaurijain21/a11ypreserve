# Google Docs Reproducibility Note

Google Docs is a cloud service, so its exact backend version cannot necessarily be pinned. The experiment date, browser/workflow/environment, observed PDF producer, source hashes, output hashes, and validation evidence were recorded. Future reruns may therefore differ after a service update. Results should be described as behavior of the dated Google Docs DOCX-to-PDF conversion pipeline, not as a timeless property of every Google Docs version.
