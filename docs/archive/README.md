# Historical archive policy

Files in the repository that describe V1, V2, pilot, pre-V3, or superseded submission states are retained for provenance. They are not current claims. The authoritative current state is `CANONICAL_SUBMISSION_STATE.md` and the machine-readable record `results/V3_PRIMARY_RESULTS.json`.

Historical evidence must not be deleted or silently rewritten merely because its taxonomy or denominator differs from the current V3 state.
