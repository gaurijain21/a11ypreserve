# Reproducibility

Quick evidence verification from the repository root:

```powershell
python reproduce.py
```

This runs the consistency audit, the separately implemented source oracle, the artifact self-check, and dependency-free classification checks. It does not pretend to reproduce authenticated Google Docs conversion or Word export when those external/session conditions are unavailable.

The frozen PDF evidence, source hashes, extraction records, contracts, and supplementary reports are included. LibreOffice reproduction is documented separately. Google repetition is recorded for the dated workflow, but future cloud behavior and credentials are not bundled.
