# Contract-component results

Component reporting decomposes each frozen fixture contract without increasing
the primary sample size. The primary unit remains one fixture/converter pair
(26 pairs; 25 classifiable). Components are explanatory rows inside a contract,
not additional observations.

| Fixture | Converter | Contract components examined | Component evidence boundary |
|---|---|---|---|
| F01 | Both | heading levels; heading sequence | destination heading nodes and order |
| F02 | Both | informative figure; alternative text | Figure `/Alt` and figure count |
| F03 | Both | item membership; nesting; ordered/unordered type | L/LI hierarchy and list-numbering attributes |
| F04 | Both | dimensions; cells; header row | Table/TR/TH/TD roles and counts |
| F05 | Both | document language | catalog/structure language value |
| F06 | Both | inline span; language override; text association | structure language spans and marked text |
| F07 | Both | informative figure; decorative state | Figure/Artifact distinction and `/Alt` |
| F08 | Both | target URI; visible-name association | annotation and structure/name association |
| F09 | Both | visible title; core title; subject; keywords | PDF metadata and visible title evidence |
| F10 | Both | header rows; groups; spans; header-cell associations | TH roles, scope/headers, ColSpan/RowSpan |
| F11 | Both | reference marker; note body; association | Note structure, nested content, and reference |
| F12 | Both | visible expression; machine-readable math structure | Formula/ActualText/token evidence |
| F14 | Both | caption text; figure association; order | Caption structure and ordered association |

The table is a reporting aid for contract coverage. It does not turn a single
fixture into repeated feature-level trials, and no component-level percentages
are used as inferential statistics.
