# V4 Reading-Order Feasibility

## Decision

**NO-GO - ORACLE NOT DEFENSIBLE.**

A bounded contract based on relative order of explicitly identified structural blocks was reconsidered. DOCX XML order is available, but a robust cross-format correspondence requires reliable mapping among PDF structure-tree order, MCIDs, marked content, drawing anchors, and text blocks across both tested pipelines. The current extractors and calibration suite do not establish that mapping with sufficient reliability.

Adding reading order would therefore create a new methodological arm after the V4 freeze without a prospective calibration/evaluation set. Reading order remains excluded from the primary 13-family denominator and is future work.
