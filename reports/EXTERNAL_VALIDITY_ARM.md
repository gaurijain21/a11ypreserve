# External-validity arm

**Decision: no natural real-world corpus was added.**

Repository searches and the recorded public-candidate review found no candidate with both stable redistribution provenance and independently inspectable feature-level source contracts. Adding unlabeled training examples would create apparent external validity without ground truth.

The project instead retains a clearly labeled secondary integrated sanity arm: three project-generated multi-feature documents, 21/21 source assertions, and 42 property–pipeline observations. It demonstrates that the protocol can be applied to documents containing multiple features, but it is synthetic, excluded from the 52-case denominator, and not a prevalence sample.
