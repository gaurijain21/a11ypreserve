# V5 external/natural DOCX validation

## Status: NO-GO for a defensible new corpus in this run

The existing realistic arm contains ten project-created integrated documents
per primary pipeline and is not natural-document evidence. A natural corpus
would require public DOCX provenance, redistribution permission, source
accessibility verification independent of A11yPreserve, and a documented
license trail. The current workspace does not contain a verified 10–20 item
corpus meeting all four conditions. No private or ambiguously licensed file is
downloaded or silently treated as external evidence.

The realistic arm therefore remains a separate applicability check, not a
prevalence estimate. The V5 external arm is deferred until legal provenance
and independent source contracts can be recorded; its absence is an explicit
limitation, not a fabricated validation result.
