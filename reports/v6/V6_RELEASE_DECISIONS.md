# V6 human release decisions

## Licensing

The root `LICENSE` is an intentional placeholder. Authors must select compatible terms for source code, generated fixtures, evidence, manuscript text, and any third-party class/style or image assets after checking ownership and redistribution rights. Do not add a license declaration by inference.

## Citation metadata

`CITATION.cff` still contains anonymous author and no-license placeholders. Authors must fill the author list, public repository URL, release version/date, and license only when attribution and public release are approved.

## Post-acceptance release checklist

- Replace anonymous author metadata in the manuscript, citation file, and package README.
- Add the approved license files and document third-party asset terms.
- Rebuild the public package from a clean checkout and regenerate all hashes.
- Remove review-only anonymization text and retain a camera-ready AI disclosure consistent with venue policy.
- Re-run the complete V6 scientific and package-integrity checks before archiving.
