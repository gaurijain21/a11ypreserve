# V6 human verification checklist

This checklist is intentionally open; the agent does not claim completion.

- [ ] Verify every cited paper exists, has correct bibliographic metadata, and supports the cited statement.
- [ ] Independently inspect V6 control, mutation, and baseline counts against the machine-readable JSON.
- [ ] Review all 10 semantically meaningful mutation survivors and confirm the wording does not imply universal sensitivity.
- [ ] Inspect the final PDF visually, confirm page count, embedded fonts, anonymity, and legibility.
- [ ] Recheck that no author names, institutions, private paths, credentials, cookies, or account identifiers appear in the anonymous source/package.
- [ ] Confirm Google Docs wording remains end-to-end and does not localize import versus export causality.
- [ ] Confirm the repeatability manifest `NOT_RUN` inconsistency is either repaired in a new V6 metadata file or disclosed as historical.
- [ ] Confirm the AI disclosure identifies tools, affected sections/code, and does not claim human verification before it occurs.
- [ ] Complete HotCRP authorship, conflicts, originality, simultaneous-submission, and artifact-access declarations.
