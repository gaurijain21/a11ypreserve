# V4 Unresolved-Case Analysis

The V4 conversion denominator is zero because no legitimate converter pipeline was available. Therefore there are no V4 conversion rows to classify as unresolved, and no unresolved rate is reported. The frozen taxonomy reserves these causes for future output rows:

1. alternate encoding not modeled;
2. insufficient extractor support;
3. ambiguous association;
4. PDF representational flexibility;
5. parser disagreement;
6. missing source–destination correspondence; and
7. unsupported contract.

When conversion is rerun, each `UNRESOLVED_EQUIVALENCE` record must contain exactly one primary cause plus corroborating evidence. A low unresolved count is not an optimization target.
