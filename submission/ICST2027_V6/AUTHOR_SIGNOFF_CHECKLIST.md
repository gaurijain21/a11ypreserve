# A11yPreserve V6 author sign-off checklist

This checklist intentionally leaves author-controlled decisions open. The
agent cannot attest to identity, authorship, legal rights, conflicts, funding,
or personal verification.

| Decision | Status | Required author action |
|---|---|---|
| Final author list and order | REQUIRES AUTHOR CONFIRMATION | Confirm exact names and order in the submission system |
| Affiliations and corresponding author | REQUIRES AUTHOR CONFIRMATION | Confirm current institutional and contact information |
| Conflicts of interest | REQUIRES AUTHOR CONFIRMATION | Enter all required HotCRP conflicts and omissions |
| Funding and acknowledgments | REQUIRES AUTHOR CONFIRMATION | Confirm whether any funding or acknowledgment is required; keep anonymous for review |
| Originality and concurrent submission | REQUIRES AUTHOR CONFIRMATION | Confirm no prior publication or concurrent review conflicts |
| AI disclosure | DRAFT PRESENT; AUTHOR APPROVAL REQUIRED | Confirm the tools, affected manuscript/code sections, extent, and responsibility statement |
| Reference verification | TECHNICAL AUDIT COMPLETE; HUMAN CONFIRMATION REQUIRED | Read all 13 cited sources and confirm metadata and claim support |
| Code and result verification | TECHNICAL AUDIT COMPLETE; HUMAN CONFIRMATION REQUIRED | Review source, executed results, and final claim wording |
| Dataset and document rights | REQUIRES AUTHOR CONFIRMATION | Confirm rights to distribute fixtures, evidence, and historical package material |
| Public code/data license | UNRESOLVED | Choose terms after review; do not infer a legal license from the repository |
| `LICENSE` and `CITATION.cff` | DEFERRED FOR ANONYMOUS REVIEW | Resolve placeholders for the appropriate release stage without exposing identity in the anonymous package |
| Replication-package release permission | REQUIRES AUTHOR CONFIRMATION | Confirm that the sanitized V6 package may be supplied to reviewers |
| Ethics/IRB or human-participant approval | NOT APPLICABLE SUBJECT TO AUTHOR CONFIRMATION | Confirm that this release contains no human-participant or assistive-technology study |
| Natural-document privacy | VERIFIED FOR CURRENT PACKAGE; AUTHOR CONFIRMATION REQUIRED | Confirm no confidential or rights-restricted natural corpus is distributed |
| Submission track and HotCRP metadata | REQUIRES AUTHOR ACTION | Select Research Papers and inspect every upload field |
| Final PDF and ZIP inspection | REQUIRES AUTHOR ACTION | Open the exact files identified in `FINAL_RELEASE_MANIFEST.md` |
| Explicit upload authorization | NOT GRANTED | Author must explicitly authorize any conference upload; no upload was performed |
